CI/CD-Pipeline

Beobachte, wie ein Build-Artefakt durch eine Continuous-Integration / Continuous-Delivery-Pipeline wandert: Commit → Build → Test → Deploy → Monitor. Die Monitor-Stufe meldet zurück an Commit — diese Rückkopplung ist das Herz von CI/CD. Injiziere einen Fehler und sieh, wie ein roter Test den gesamten Release stoppt.

Worauf du achten solltest Starte einmal mit alles-grün, dann drücke Fehler injizieren und starte erneut. Das Artefakt stoppt bei Test und Deploy zeigt ein rotes ✗ — ein fehlgeschlagener Test blockiert den Release. Beobachte dann den Rückkopplungspfeil von Monitor zurück zu Commit: Diese Schleife ist der Grund, warum Teams Probleme früh finden, bevor sie zu Nutzern gelangen.
