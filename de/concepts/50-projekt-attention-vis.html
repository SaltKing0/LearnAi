50 · Mini-Projekt: Attention-Visualisierung

Erklär es einem 12-Jährigen Du baust genau das Bild, das du in Konzept 03 gesehen hast — aber selbst. Ein Raster, das zeigt: welches Wort schaut wie stark auf welches andere. So wird aus „gelesen“ → „selbst gemacht“.

Was du brauchst

  • Attention-Theorie (03) — Q/K/V, Softmax, Temperatur.
  • Die Demo (playground/attention-demo.html) als Vorlage.
  • p5.js / Canvas — Heatmap zeichnen.

Die Visualisierung (selbst gebaut)

Gib einen Satz ein — die Heatmap zeigt, welches Wort wie stark auf welches andere schaut. Die Scores entstehen hier echt aus einer Self-Attention- Rechnung (Q·K, dann Softmax über Temperatur), nur mit toy- Embeddings statt gelernten. Probier den Pronomen-Satz und schau, was „er“ fokussiert.

Temperatur: 1.0  ·  Head:

Zeile zum Hervorheben: —

flowchart LR W[Wörter] --> E["Embedding je Wort (toy)"] E --> QK["Score = Q·K (Dot-Product)"] QK --> SM["Softmax über Temperatur"] SM --> H["Heatmap: Zeile i schaut auf Spalte j"]

Genau diese Kette steckt in jedem Transformer-Layer (Konzept 03/04).

Erweiterungsideen

  • Echte Scores aus einem kleinen Modell (11) statt der simulierten (03).
  • Mehrere Heads nebeneinander zeigen (Multi-Head, 03/04).
  • Wort-Eingabe: welches Pronomen schaut auf welches Nomen (Kern-Beispiel 03)?
