58 · DevOps, Infrastruktur & Cloud

Erklär es einem 12-Jährigen DevOps heißt: dafür sorgen, dass deine App sicher und automatisch vom Laptop in die echte Welt kommt. Statt „bei mir läuft's" verpackst du sie in eine Box (Docker), lässt die Checks automatisch laufen (CI), schickst sie raus (CD) und behältst sie im Auge (Monitoring). Die Cloud ist einfach, jemand anderem riesigen Computer zu mieten statt einen eigenen zu kaufen.

Intuition

Software zählt nur, wenn sie zuverlässig in Produktion läuft. DevOps ist die Sammlung von Praktiken, die die Reise vom Code zum laufenden Dienst und zurück automatisieren: verpacken, testen, ausliefern, beobachten. Für KI ist das doppelt wichtig — Modelle sind schwer, GPUs knapp, und Inferenz muss laufen und beobachtbar bleiben.

Containerisierung & Orchestrierung

  • Docker: verpackt deine App + ihre exakte Umgebung in ein Container-Image — „läuft überall gleich." Der De-facto-Standard.
  • Podman: eine Docker-kompatible, daemon-lose Alternative (sicherere Defaults, rootless).
  • Kubernetes (K8s): orchestriert viele Container über viele Maschinen — Skalierung, Neustarts, Load Balancing, Rolling Deploys. Mächtig, aber komplex.

CI/CD-Pipelines

flowchart LR C["Commit / PR"] --> CI["CI: Build + Lint + Unit-Tests + Evals"] CI --> CD["CD: Image bauen, deployen"] CD --> P["Produktion"] P --> M["Monitoring: Logs, Metriken, Alerts"] M -->|"Feedback"| C

Die CI/CD-Schleife — automatisierte Checks vor dem Deploy, Monitoring danach. Für KI gehören zu „Tests" auch Evals auf Modellausgabe.

  • GitHub Actions / GitLab CI: Pipelines in YAML im Repo definieren; läuft bei jedem Push/PR.
  • Jenkins: älter, selbst gehostet, sehr flexibel.
  • Automatisierte Build→Test→Deploy-Workflows machen Releases sicher und häufig.

Cloud & Infrastructure as Code (IaC)

  • Cloud-Provider: AWS, Google Cloud, Azure — Compute, Speicher, GPUs, Managed Services mieten.
  • IaC: Infrastruktur in Code definieren, nicht per Klick. Terraform (provider-agnostisch) und CloudFormation (AWS-nativ) lassen deine ganze Infra wie Code versionieren und reviewen.
  • GPU-spezifisch: für KI brauchst du oft GPU-Instanzen oder Serverless-GPU — dieselben Cloud-Muster, nur teurer (17).

Observability

  • Logging: strukturierte Ereignisaufzeichnungen (was passierte).
  • Metriken: numerische Zähler/Gauges (Requests/Sek., Latenz, Fehlerrate).
  • Distributed Tracing: einem Request über viele Dienste folgen (OpenTelemetry ist der Standard).
  • Tools: Prometheus + Grafana (Open-Source-Metriken + Dashboards), Datadog (SaaS), OpenTelemetry (der Sammel-Standard).

Warum hilft mir das (als KI-/Code-Nutzer)

  • Modelle deployen: vLLM/TGI als Container, orchestriert mit Docker/K8s, hinter einer Serving-Ebene (33).
  • Eval in CI: Evals und LLM-as-Judge bei jeder Änderung automatisch laufen lassen (34).
  • Kostenkontrolle: Autoscaling und richtiges Dimensionieren von GPU-Instanzen sind DevOps-Entscheidungen, die ins Budget gehen (17).
  • Observability von Agents: eine Agent-Schleife über Modell + Tools zu tracen ist Distributed Tracing im Kleinen.
