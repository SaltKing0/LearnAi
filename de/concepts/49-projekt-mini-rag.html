49 · Mini-Projekt: Mini-RAG

Erklär es einem 12-Jährigen Stell dir eine Kiste mit deinen eigenen Zetteln vor. Du stellst eine Frage, das Programm sucht die passenden Zettel heraus und gibt sie dem Modell, damit es daraus antwortet — statt zu raten.

Bausteine (aus bisherigen Stufen)

  • Embeddings (02) — Zettel in Vektoren wandeln.
  • Vektorsuche (08) — ähnlichste Chunks zur Frage finden.
  • Augmentierter Prompt (07) — Chunks + Frage an die API (12).

Flow (vereinfacht)

# 1) Index bauen (einmal)
chunks = split(docs)
vecs   = embed(chunks)            # Konzept 02

# 2) Frage beantworten
q_vec  = embed(question)
top    = nearest(vecs, q_vec, k=3) # Konzept 08
prompt = f"Kontext:\n{top}\n\nFrage: {question}"
answer = llm(prompt)               # Konzept 12

Aufgaben

  • Nimm deine eigenen Textdateien (Notizen, Docs).
  • Nutze eine Vektordatenbank (Chroma/pgvector) statt In-Memory (08).
  • Zitate mitgeben, damit die Antwort verifizierbar ist (16).
