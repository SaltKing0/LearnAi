25 · Mini-Projekt: LoRA trainieren

Erklär es einem 12-Jährigen Statt das ganze große Modell umzubauen, nähst du ihm einen kleinen Zusatz-Anhänger an, der genau dein Thema lernt. Hinterher hast du eine kleine Datei, die du jederzeit an- und abschalten kannst (Konzept 10).

Bausteine

  • Fine-Tuning/PEFT (10) — LoRA-Adapter trainieren.
  • Hugging Face (11) — Bibliothek + Modell laden.
  • Training-Intuition (05) — Loss, Epochen, Lernrate.
  • Notebook (13) — bequemer Startpunkt.

Skelett (PEFT)

from peft import LoraConfig, get_peft_model
from transformers import AutoModelForCausalLM, Trainer

base = AutoModelForCausalLM.from_pretrained("mistralai/Mistral-7B")
cfg  = LoraConfig(r=8, lora_alpha=16, target_modules=["q_proj","v_proj"])
model = get_peft_model(base, cfg)   # nur Adapter trainierbar (10)

trainer = Trainer(model=model, train_dataset=data, args=training_args)
trainer.train()                      # derselbe Loop wie 05
