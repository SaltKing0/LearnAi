32 · Multi-Modal Modelle

Erklär es einem 12-Jährigen Stell dir ein Modell ist wie jemand der nur lesen kann (Text). Jetzt gib ihm Augen (Bilder), Ohren (Audio) und Hände (Video). Plötzlich kann es nicht nur einen Satz verstehen, sondern ein Meme erklären, ein Diagramm lesen oder einem Flöte spielen zeigen. Das ist Multi-Modalität.

Was bedeutet Multi-Modal?

Multi-Modal = das Modell verarbeitet mehrere Eingabetypen (Modalitäten): Text, Bilder, Audio, Video, Code, Sensordaten. Die Zukunft gehört Modellen die all diese Sprachen sprechen.

Die Modalitäten

ModalitätBeispiel-ModellUse-Case
Text → TextGPT-4, ClaudeChat, Code, Analyse
Text + Bild → TextGPT-4V, Claude 3.5 SonnetBildbeschreibung, OCR, UI-Analyse
Text → BildDALL-E, Midjourney, Stable DiffusionBildgenerierung, Design
Audio → TextWhisperTranskription, Übersetzung
Text → AudioElevenLabs, BarkVoice-Cloning, Musik
Text + Video → TextGemini 1.5 ProVideoanalyse, Zusammenfassung

Architektur-Herausforderungen

  • Fusion → Wie kombiniert man Text- und Bild-Embeddings?
  • Alignment → „Hund" im Text = „Hund" im Bild. Das Modell muss die Verbindung lernen.
  • Kosten → Bilder brauchen mehr Tokens als Text (ein Bild = 1000+ Tokens).
  • Qualität → Ein schlechtes Bild führt zu schlechten Antworten.

Praktische Anwendungen

  • Dokumenten-Analyse → Screenshots, Rechnungen, Tabellen automatisch lesen
  • UI-Testing → Bot sieht den Screen und erkennt Bugs
  • Code-Review → Pull Requests mit Screenshots kommentieren
  • Accessibility → Blinde Menschen Bilder beschreiben lassen
  • Video-Zusammenfassung → YouTube-Videos in Threads umwandeln
