29 · Function Calling (Deep Dive)

Erklär es einem 12-Jährigen Stell dir vor, du bist in einem Restaurant. Du sagst dem Kellner "Ich möchte die Speisekarte". Der Kellner bringt sie dir. Function Calling ist wie dieser Kellner — das Modell sagt "Ich brauche das jetzt" und das Tool liefert es.

Der Loop im Detail

  1. User fragt: "Wie ist das Wetter in Berlin?"
  2. Modell erkennt: "Ich brauche Wetterdaten" → gibt Function-Call aus
  3. Dein Code führt das Tool aus: get_weather("Berlin")
  4. Ergebnis wird dem Modell zurückgegeben
  5. Modell formuliert Antwort: "In Berlin sind 18°C und sonnig"

Tool-Definition (OpenAI-Format)

{
  "name": "get_weather",
  "description": "Get current weather for a city",
  "parameters": {
    "type": "object",
    "properties": {
      "city": {
        "type": "string",
        "description": "The city name"
      }
    },
    "required": ["city"]
  }
}

Multi-Tool Calls

Modell kann mehrere Tools gleichzeitig aufrufen:

// Modell gibt zwei Calls zurück:
[
  { "name": "get_weather", "args": { "city": "Berlin" } },
  { "name": "get_weather", "args": { "city": "München" } }
]

Error Handling

Was wenn das Tool fehlschlägt?

  • Retry → Modell versucht es mit anderen Parametern
  • Fallback → Alternative Tools vorschlagen
  • User fragen → "Ich konnte das nicht finden, meinst du...?"

Streaming mit Function Calls

Bei Streaming kommen die Calls Stück für Stück. Dein Code muss "Function Call Accumulation" machen — die Teile sammeln und erst ausführen wenn alles da ist.
