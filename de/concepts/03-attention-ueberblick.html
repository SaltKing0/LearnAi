03 · Attention (Selbst-Aufmerksamkeit)

Erklär es einem 12-Jährigen Wenn du den Satz liest „Der Hund beißt den Mann, weil er hungrig ist“, musst du wissen: Wer ist „er“? Der Hund oder der Mann? Attention ist das, was dem Modell erlaubt, bei jedem Wort hinzuschauen, welche anderen Wörter gerade wichtig sind — um „er“ dem „Hund“ zuzuordnen.

Die Idee in einem Satz

Jedes Token berechnet für jedes andere Token eine Gewichtung: „wie viel Aufmerksamkeit schenke ich dir?“ Diese Gewichte bestimmen, welche Informationen in die Bedeutung des aktuellen Tokens einfließen.

Wie die Gewichte entstehen (vereinfacht)

Für jedes Token gibt es drei Vektoren, die das Modell gelernt hat:

  • Query (Q) — „wonach suche ich?“
  • Key (K) — „worauf ich passe“
  • Value (V) — „was ich beitrage“

Score zwischen Token i und j = Ähnlichkeit von Qi mit Kj. Diese Scores werden über alle j mit Softmax zu Gewichten normalisiert (Summer = 1). Dann ist der neue Vektor von Token i = gewichtete Summe aller Vj. Das ist Attention.

Temperatur = Schärfe des Blickfelds

Softmax hat eine implizite „Temperatur“: Teilt man die Scores vor dem Softmax durch eine kleine Zahl (tiefe Temperatur), werden die Gewichte scharf/peakig — das Modell fixiert sich auf wenige Wörter. Bei hoher Temperatur werden sie weich/uniform — es schaut überall gleich viel hin. Genau dieselbe Temperatur-Logik steckt hinter dem temperature-Parameter beim Generieren (Konzept 01).

Warum das die „magische“ Komponente ist

Transformer = gestapelte Attention-Lagen. Mehrere „Köpfe“ (Multi-Head) schauen gleichzeitig auf unterschiedliche Beziehungen (Grammatik, Kern-Akteur, Zeit). Daraus entsteht das, was sich wie „Verständnis“ anfühlt — ist aber nur gewichtete Informationsmischung. Kein Wunder, dass Halluzinationen entstehen, wenn die Gewichte das falsche Wort fokussieren.
