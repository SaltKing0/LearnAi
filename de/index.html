Wie dieses Repo wächst

Jede neue Sache, die du lernst, wird zu einer Konzept-Seite (Kopie von concepts/_template.html) + einem Eintrag in assets/nav.js (in der passenden Stufe). Fertig. Kein Framework, kein Build-Step — es läuft direkt auf GitHub Pages.
