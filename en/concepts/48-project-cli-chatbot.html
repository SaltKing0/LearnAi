48 · Mini-Project: CLI Chatbot

Explain it to a 12-year-old We build a small terminal program that chats with an AI model. You type, it answers. This is the first time all the previous concepts (API, prompts, streaming) come together into something usable.

What you need (from previous stages)

  • LLM API (12) — key + endpoint.
  • System prompt (07) — set the role.
  • Streaming (12) — output the answer live.
  • Loop (01) — you run the chat as a loop.

Skeleton (Python, OpenAI-compatible)

import os, openai
client = openai.OpenAI(api_key=os.environ["OPENAI_KEY"])
msgs = [{"role":"system","content":"You are a helpful bot."}]
while True:
    q = input("You> ")
    if q == "exit": break
    msgs.append({"role":"user","content":q})
    r = client.chat.completions.create(model="gpt-4o-mini",
        messages=msgs, stream=True)
    print("Bot> ", end="")
    txt = ""
    for chunk in r:
        d = chunk.choices[0].delta.content or ""
        print(d, end=""); txt += d
    msgs.append({"role":"assistant","content":txt})
    print()

Note: the history (msgs) is carried along — exactly the autoregressive context from Concept 01. Without it the bot "forgets" everything.
