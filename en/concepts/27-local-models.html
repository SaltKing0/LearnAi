27 · Local Models (Ollama, LM Studio, vLLM)

Explain it to a 12-year-old Imagine you want to bake a cake. So far you always go to a baker (API) and buy the cake. Local models are like your own oven — you can bake cakes whenever you want, they cost nothing per piece, but you have to afford the oven (GPU).

Why local?

  • Privacy → Data never leaves your device
  • Cost → No API costs per use
  • Offline → Works without internet
  • Control → You decide when to update

Quantization

Large models don't fit in every memory. Quantization reduces precision (e.g., from 16-bit to 4-bit) — the model becomes smaller, minimally worse.

Quickstart with Ollama

# Install Ollama
brew install ollama  # Mac
# or: https://ollama.com/download

# Download model
ollama pull llama3.1

# Run model
ollama run llama3.1

# API mode (for your own tools)
ollama serve
# then: curl http://localhost:11434/api/generate
