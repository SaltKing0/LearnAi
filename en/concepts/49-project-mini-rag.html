Project 49 · Stage G (Practice)

49 · Mini-Project: Mini-RAG

Explain it to a 12-year-old Imagine a box with your own notes. You ask a question, the program picks out the matching notes and gives them to the model so it answers from them — instead of guessing.

Building blocks (from previous stages)

  • Embeddings (02) — turn notes into vectors.
  • Vector search (08) — find the most similar chunks to the question.
  • Augmented prompt (07) — chunks + question to the API (12).

Flow (simplified)

# 1) Build index (once)
chunks = split(docs)
vecs   = embed(chunks)            # Concept 02

# 2) Answer a question
q_vec  = embed(question)
top    = nearest(vecs, q_vec, k=3) # Concept 08
prompt = f"Context:\n{top}\n\nQuestion: {question}"
answer = llm(prompt)               # Concept 12

Tasks

  • Use your own text files (notes, docs).
  • Use a vector database (Chroma/pgvector) instead of in-memory (08).
  • Include citations so the answer is verifiable (16).
