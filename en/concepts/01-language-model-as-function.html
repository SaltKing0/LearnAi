01 · Language Model as Function

Explain it to a 12-year-old A language model is like someone who gets a sentence half-read and always guesses just the *next word* — but very, very well. It does this word by word until the sentence is finished. That's all it is. Everything else is technique to make this one prediction good.

The one equation

Everything an LLM does is this prediction, over and over:

P( next_token | all_previous_tokens )

The model outputs a probability for every possible next word. We pick one (the most likely, or randomly by temperature) and append it. Then again from the top. This is the entire "generation loop".

The loop, visualized

Animation: the model writes word by word. Each step feeds what was written back in.

What you actually call as an API user

When you call openai.chat.completions.create(...) or the equivalent from another provider, exactly this loop happens internally — just that the provider runs it server-side and returns the finished result (or token stream) to you. Parameters you know:

  • temperature → how "random" the next word is chosen (see Attention demo for the principle).
  • max_tokens → when the loop stops.
  • top_p / top_k → restricts the candidate pool before selection.
  • stop → explicit stop word for the loop.

Why this matters

Because the model doesn't "know" anything and doesn't "plan" — it just guesses the next word. Hallucination loops, repetition loops, "it's thinking" (actually: more loop iterations) — all follow from this one mechanism. Once you internalize it, LLM behavior explains itself.
