Concept 30 · Stage D

30 · LLM APIs Practically

Explain it to a 12-year-old Instead of running the model yourself on your computer, you send your question over the internet to a company that does that for you. You get the answer back — piece by piece, like a typesetter typing it out live.

The three things you really need

  • System Prompt — sets the role/rules (Concept 07). In the API it's usually a separate message type role: "system".
  • Streaming — instead of waiting until the whole text is done, it arrives token by token (as Concept 01 generates). Better UX, easier to build than it sounds.
  • Tool-Calls — the model requests tools (Concept 09); the API returns them structured, you execute them and send the result back.

The API call (simplified, OpenAI-compatible)

client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system",    "content": "You are a precise assistant."},
        {"role": "user",      "content": "What is 17*23?"},
    ],
    temperature=0.2,   # low = factually faithful
    stream=True,       # token by token
)
