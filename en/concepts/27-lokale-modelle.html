27 · Lokale Modelle (Ollama, LM Studio, vLLM)

Explain it to a 12-year-old Stell dir vor, du willst ein Kuchen-backen. Bisher gehst du immer zu einem Bäcker (API) und kaufst den Kuchen. Lokale Modelle sind wie ein eigener Backofen — du kannst die Kuchen backen wann du willst, sie kosten nichts pro Stück, aber du musst dir den Backofen (GPU) leisten.

Warum lokal?

  • Datenschutz → Daten verlassen dein Gerät nie
  • Kosten → Keine API-Kosten nach Nutzung
  • Offline → Funktioniert ohne Internet
  • Kontrolle → Du bestimmst wann geupdated wird

Quantisierung

Große Modelle passen nicht in jeden Speicher. Quantisierung reduziert die Präzision (z.B. von 16-bit auf 4-bit) — das Modell wird kleiner, minimal weniger gut.

  • Q4 → 4-bit, kleinster Speicherverbrauch
  • Q5 → 5-bit, guter Kompromiss
  • Q8 → 8-bit, fast keine Qualitätseinbußen

Schnellstart mit Ollama

# Ollama installieren
brew install ollama  # Mac
# oder: https://ollama.com/download

# Modell herunterladen
ollama pull llama3.1

# Modell starten
ollama run llama3.1

# API-Modus (für eigene Tools)
ollama serve
# dann: curl http://localhost:11434/api/generate
