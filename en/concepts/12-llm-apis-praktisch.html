Concept 12 · Stage D

12 · LLM-APIs praktisch

Explain it to a 12-year-old Statt das Modell selbst auf dem Computer laufen zu lassen, schickst du deine Frage ans Internet zu einer Firma, die das für dich macht. Du bekommst die Antwort zurück — Stück für Stück, wie ein Typograf, der live mitschreibt.

Die drei Dinge, die du wirklich brauchst

  • System-Prompt — setzt Rolle/Regeln (Concept 07). In der API meist ein eigener Nachrichtentyp role: "system".
  • Streaming — statt zu warten, bis der ganze Text fertig ist, kommt er Token für Token (wie Concept 01 generiert). Besseres UX, einfacher zu bauen, als es klingt.
  • Tool-Calls — das Modell fordert Werkzeuge an (Concept 09); die API liefert sie strukturiert zurück, du führst sie aus und schickst das Ergebnis zurück.

Der API-Aufruf (vereinfacht, OpenAI-kompatibel)

client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system",    "content": "Du bist ein präziser Helfer."},
        {"role": "user",      "content": "Wie viel ist 17*23?"},
    ],
    temperature=0.2,   # niedrig = faktentreu
    stream=True,       # Token für Token
)

Warum das für dich als Code-Nutzer zentral ist

    
    
      
  • Komplett-Service: keine GPU, kein Modell-Download nötig.
    • 
      
  • Streaming macht Apps gefühlt schnell (erstes Zeichen sofort).
    • 
      
  • Tool-Calls = die Brücke zu Agents (09) ohne eigenen Server.
    • 
      
  • Kosten steuern: max_tokens, Modellwahl, Caching.
