09 · Agents / Tool-Use

Explain it to a 12-year-old Imagine you have a smart assistant. You say "What's the weather?" and it tells you. But what if you say "If it's raining tomorrow, text my mom we'll stay home"? The assistant needs to check the weather (tool 1), make a decision (reasoning), and send a text (tool 2). That's an agent — a model that can use tools.

What is an Agent?

An agent is a model that can take actions in the world — not just answer questions, but call APIs, run code, send emails, query databases. The model decides which tool to use, when, and with what parameters.

The Agent Loop

  1. Observe → What is the current state?
  2. Think → What should I do next?
  3. Act → Call a tool
  4. Observe → What was the result?
  5. Repeat → Until task is complete

Types of Tools

  • APIs → Weather, stocks, news
  • Code execution → Run Python, SQL
  • Web browsing → Search, scrape
  • File operations → Read, write, delete
  • Communication → Email, Slack, SMS

Why this matters to you

  • Automation → Build bots that do real work
  • Multi-step tasks → Break complex problems into steps
  • Reliability → Tools provide ground truth, not just model knowledge
