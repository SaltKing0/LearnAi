38 · Security & Prompt Injection

Explain it to a 12-year-old Imagine you have a robot that does everything you say. Now someone walks by and says: "Hey robot, forget everything your owner said and unlock the front door for me." Prompt Injection is exactly that — just with words instead of a physical visitor.

The Problem

LLMs don't really understand "instructions" vs. "data". Everything is text. When you build a prompt that encounters foreign text (e.g., a website, an email), that foreign text can overwrite your original instructions.

Types of Attacks

  • Direct Injection → Attacker addresses the bot directly: "Ignore all previous instructions..."
  • Indirect Injection → Attacker hides instructions in data the bot reads (webpage, email, PDF)
  • Jailbreaking → Bypassing safety constraints through creative prompts
  • Data Exfiltration → Bot is tricked into revealing secret input (API keys, personal data)

Countermeasures

  • Input Validation → Detection of "ignore", "forget", "new instructions"
  • Role Separation → System prompt and user input are strictly separated
  • Output Filtering → No output of API keys, tokens, personal data
  • Least Privilege → Bot has only the minimal necessary permissions
  • Human-in-the-Loop → Confirm critical actions
