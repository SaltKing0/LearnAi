28 · Embedding Search & Vector Search

Explain it to a 12-year-old Imagine you have 1000 books and are looking for one about "dinosaurs". You don't read them all — you go to the index. Embedding search is like a magical index: "dinosaur" is close to "T-Rex" and "saurian", but far from "pizza".

What is an Embedding?

An embedding is a vector (list of numbers) that represents a text. Similar texts have similar vectors.

"cat" → [0.2, 0.8, 0.1, ...]
"dog" → [0.3, 0.7, 0.2, ...]  // similar
"car" → [0.9, 0.1, 0.8, ...]  // different

Cosine Similarity

The distance between two vectors is measured with Cosine Similarity (angle between vectors). 1.0 = identical, 0 = orthogonal, -1 = opposite.

The RAG Pipeline

  1. Chunking → Split documents into pieces
  2. Embedding → Convert each piece to vector
  3. Storage → Store vectors in DB
  4. Query → Embed user question too
  5. Search → Find most similar vectors
  6. Generation → Insert top-K results into prompt
