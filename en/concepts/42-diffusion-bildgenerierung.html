42 · Diffusion & Image Generation

Explain it to a 12-year-old Take a photo and keep adding confetti (noise) until nothing is recognizable. A diffusion model learns the reverse trick: looking at pure confetti, it removes exactly a bit of it step by step until an image remains. "Draw me an astronaut cat" means: start with random confetti and remove everything that does NOT look like an astronaut cat.

The basic principle: removing noise

  • Forward (training): a real image gets covered with Gaussian noise in many small steps. The model learns to predict the noise added at each step.
  • Reverse (generation): start from pure noise; the model removes its predicted noise step by step → an image emerges from nothing.
  • Guidance: the text prompt controls which noise gets removed (via cross-attention on text embeddings, usually a CLIP-style text encoder).
flowchart LR T[Text prompt] --> E[Text encoder
e.g. CLIP/T5] N[(Pure noise)] --> D[U-Net / DiT
"predict the noise"] E -->|guidance| D D --> X1[less noisy] X1 -->|step 2…n| D X1 -.->|after ~20-50 steps| B[Final image]

Iterative denoising: the same network block runs 20–50× and scrapes off a bit of noise each step.

Key terms

TermMeaning
Latent diffusion / SDDenoising not in pixel space but in a compressed latent space (VAE) — vastly cheaper. The basis of Stable Diffusion.
U-Net / DiTThe architecture predicting the noise. DiT (Diffusion Transformer) is the modern standard.
Scheduler / stepsHow big the denoising steps are. More steps = more detailed but slower.
CFG scaleHow strictly the prompt is followed. High = prompt-faithful but "burned out"; low = creative/drifting.
SeedThe starting noise. Same seed + same prompt = same image (reproducible).
LoRA / fine-tuneTeaching a style or person afterwards (Concept 10) — standard in images too.

Why this is central for you as a code user

  • Understand the cost profile: image generation is iterative — steps × model size determine price/latency (cf. Concept 17).
  • Feasible locally: SD models run (quantized) on consumer GPUs — unlike frontier LLMs (Concept 27).
  • Same building blocks as LLMs: text encoding, latency, sampling, fine-tuning/LoRA — your LLM knowledge transfers.
  • Multi-modal round trip: models like Gemini/nano-banana both generate AND understand images — see Concept 32.
