32 · Multi-Modal Models

Explain it to a 12-year-old Imagine a model as someone who can only read (text). Now give it eyes (images), ears (audio) and hands (video). Suddenly it can't just understand a sentence — it can explain a meme, read a diagram, or describe someone playing the flute. That's multi-modality.

What does multi-modal mean?

Multi-modal = the model processes multiple input types (modalities): text, images, audio, video, code, sensor data. The future belongs to models that speak all of these languages.

The modalities

ModalityExample modelsUse case
Text → TextGPT-4, ClaudeChat, code, analysis
Text + Image → TextGPT-4V, Claude 3.5 SonnetImage description, OCR, UI analysis
Text → ImageDALL-E, Midjourney, Stable DiffusionImage generation, design
Audio → TextWhisperTranscription, translation
Text → AudioElevenLabs, BarkVoice cloning, music
Text + Video → TextGemini 1.5 ProVideo analysis, summarization

Architecture challenges

  • Fusion → How do you combine text and image embeddings?
  • Alignment → "dog" in text = "dog" in an image. The model must learn that connection.
  • Cost → Images need more tokens than text (one image = 1000+ tokens).
  • Quality → A bad image leads to a bad answer.

Practical applications

  • Document analysis → automatically read screenshots, invoices, tables
  • UI testing → bot sees the screen and recognizes bugs
  • Code review → comment on pull requests with screenshots
  • Accessibility → describe images for blind people
  • Video summarization → turn YouTube videos into threads
