13 · Notebook Workflow

Explain it to a 12-year-old A notebook is like a notepad where code and explanation sit side by side and you can run each section on its own. If one piece doesn't work, you only change that one and try it again — without rewriting the whole notepad.

What a notebook is

A Jupyter/Colab notebook is a sequence of cells: sometimes text (Markdown), sometimes executable code (Python). You run cell by cell; the state (variables, loaded models) is kept for the next one. That's perfect for experimental AI work — exactly what you do in this course.

Why notebooks are so common in AI

  • GPU in the cloud: Colab gives you a (free) GPU — needed for inference/training of large models (Concept 06).
  • Reproducible: you share the notebook, someone else clicks "Run all" and sees the same thing.
  • Interactive: intermediate results, plots, demos visible immediately.
