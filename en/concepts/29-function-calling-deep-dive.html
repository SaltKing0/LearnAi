29 · Function Calling (Deep Dive)

Explain it to a 12-year-old Imagine you're in a restaurant. You say to the waiter "I'd like the menu". The waiter brings it to you. Function Calling is like that waiter — the model says "I need this now" and the tool delivers it.

The Loop in Detail

  1. User asks: "What's the weather in Berlin?"
  2. Model recognizes: "I need weather data" → outputs function call
  3. Your code executes the tool: get_weather("Berlin")
  4. Result is returned to the model
  5. Model formulates answer: "In Berlin it's 18°C and sunny"

Tool Definition (OpenAI Format)

{
  "name": "get_weather",
  "description": "Get current weather for a city",
  "parameters": {
    "type": "object",
    "properties": {
      "city": {
        "type": "string",
        "description": "The city name"
      }
    },
    "required": ["city"]
  }
}

Multi-Tool Calls

Model can call multiple tools simultaneously:

// Model returns two calls:
[
  { "name": "get_weather", "args": { "city": "Berlin" } },
  { "name": "get_weather", "args": { "city": "Munich" } }
]

Error Handling

What if the tool fails?

  • Retry → Model tries with different parameters
  • Fallback → Suggest alternative tools
  • Ask user → "I couldn't find that, did you mean...?"
