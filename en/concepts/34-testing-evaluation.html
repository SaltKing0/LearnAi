34 · Testing & Evaluation

Explain it to a 12-year-old Imagine you have a robot that solves math problems. How do you find out if it's good? You give it 100 problems and see how many it gets right. But what if it memorized instead of understanding? Testing AI is exactly this exam — just that the problems are much more complicated.

Why Testing LLMs is hard

  • Non-deterministic → same question, different answers
  • No clear "correct" → "Tell a joke" has no gold standard
  • Hallucinations → wrong answers often sound more correct than right ones
  • Context-dependent → an answer can be right here, wrong there

Types of Tests

  • Unit Tests → Test specific behaviors (sentiment, format, no leaks)
  • Evaluation Datasets → MMLU, GSM8K, HumanEval, HellaSwag
  • LLM-as-Judge → Strong LLM evaluates weaker one's responses
  • Integration Tests → End-to-end user flows, regression, performance
