15 · Transformer Overview

Explain it to a 12-year-old Imagine a factory assembly line. At each station, a worker improves the product a little. The Transformer is like a factory with dozens of stations — each one refines the understanding of the sentence a bit more. By the end, the product is a deep understanding of what the text means.

What is a Transformer?

The Transformer is the architecture behind GPT, Claude, LLaMA, and most modern LLMs. Introduced in 2017 ("Attention Is All You Need"), it replaced older architectures (RNNs, LSTMs) with a purely attention-based design.

The Architecture

  1. Input Embedding → Tokens become vectors
  2. Positional Encoding → Where in the sequence?
  3. N Encoder/Decoder Layers → Each with:
    • Multi-Head Self-Attention
    • Feed-Forward Network (FFN)
    • Layer Normalization
  4. Output Head → Predict next token

Encoder vs. Decoder

WhatUnderstands inputGenerates output
AttentionBidirectional (sees all)Causal (only previous)

Why this matters to you

  • Context length → More layers = better understanding, but slower
  • Model size → 7B, 70B = number of parameters, mostly in FFN layers
  • Inference cost → Each token requires a full pass through all layers
