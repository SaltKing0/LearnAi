Context Window

Watch how context grows with each loop step (O(n²)): the stable prefix (system prompt + prior conversation) is cached and cheap; the volatile tail (time, file listing) changes. Once the compaction threshold is reached, old tool results are replaced by a summary — otherwise costs explode.

What to watch for Without compaction the context fills up and every turn gets pricier. With early compaction usage stays flat — that's why context engineering is the biggest cost lever.
