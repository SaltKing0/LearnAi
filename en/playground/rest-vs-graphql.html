REST vs GraphQL

Ask the same question — who is user 1 and what did they post? — the REST way and the GraphQL way. REST makes multiple round-trips to different endpoints and hands back extra fields you never asked for (over-fetching). GraphQL sends one query to one endpoint and gets back exactly the fields it requested. Watch the arrows fly.

What to watch for REST: many endpoints (/users/1, /users/1/posts) and each response drags along extra data you don't need. GraphQL: one query, exact fields — but the setup (schema, resolvers, a server that speaks GraphQL) is more complex.
