Same Problem, 3 Paradigms

Three programming paradigms solve the exact same problem — summing a list of numbers. Each bar is one number; green = already added to the running total, red = the number being added right now. Switch paradigms: the result is always the same, only the structure of the thinking changes.

What to watch for The result is always the same — only the structure changes. Object-oriented holds the state in an object, functional is pure (same input → same output), imperative is step-by-step. Watch the order of addition: imperative and OOP add left to right, functional folds right to left.
