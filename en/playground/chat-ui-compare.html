Chat UI in 2 Frameworks

The same minimal chat interface, rendered two ways. Type a message and send it: both panels update with the identical message list — but they reach that result by completely different mechanisms. React builds a component tree and diffs a virtual DOM at runtime; Svelte compiles your reactive let into direct DOM updates at build time.

What to watch for The two panels give you the same chat UX — identical bubbles, identical updates. The difference is invisible on screen: React runs a runtime diff over a virtual DOM on every update, while Svelte compiled the update logic away at build time and touches the real DOM directly. Same result, different engine.
