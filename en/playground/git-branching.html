Git Branching Strategies

Watch two Git branching strategies build the same history: Gitflow and trunk-based development. Each dot is a commit; each colored lane is a branch. Press Play or Step to watch branches appear, diverge, and merge back together.

What to watch for In trunk-based development every merge lands straight on main, so main is always deployable. Gitflow adds develop, feature, release, and hotfix branches — more structure for planning releases, but more branches that must be kept in sync.
