Prompt Injection

Watch how a crafted message can hijack a model. The system prompt at the top holds a hidden rule. Send a normal question and the model behaves; switch to an injected message and the same input field makes the model reveal its secret. This is why you sandbox AI and treat model output as untrusted.

What to watch for The same input field, but crafted text changes the model's behavior entirely. The model doesn't "know" the difference between the system prompt and your message — it just follows instructions in order. Untrusted input can override the system prompt, so sandbox the model and never trust its output blindly.
