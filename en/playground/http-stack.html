HTTP & the TCP/IP Stack

Send an HTTP request and watch it descend the stack — each layer wraps the payload in its own envelope (encapsulation) — then the response ascend back, unwrapping in reverse. HTTPS just adds an encryption envelope at the top.

What to watch for Each layer wraps the payload like an envelope, and the response unwraps it in reverse. The Transport layer (TCP) adds reliability, the Internet layer (IP) adds addressing, and the Link layer puts it on the wire.
