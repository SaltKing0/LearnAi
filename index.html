AI-Lernkurs

Ein wachsendes, interaktives Wiki — gebaut, um KI wirklich zu verstehen, nicht nur zu benutzen. Jedes Konzept = eine Seite + eine interaktive Demo.

Die eine Regel Zu jedem Konzept gibt es einen Satz „Erklär es einem 12-Jährigen“. Wenn du den nicht schreiben kannst, hast du es noch nicht verstanden.

Wie dieses Repo wächst

Jede neue Sache, die du lernst, wird zu einer Konzept-Seite (Kopie von concepts/_template.html) + einem Eintrag in assets/nav.js. Fertig. Kein Framework, kein Build-Step — es läuft direkt auf GitHub Pages.

Details & Roadmap: README.md und ROADMAP.md im Repo-Root.
